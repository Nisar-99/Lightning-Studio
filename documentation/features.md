 # ✨ Feature Highlights

Everything you need for efficient Salesforce development — all in your browser.

---

#### 🚀 Quick Development  
Create or update:
- **Lightning Web Components (LWC)**
- **Lightning Message Service (LMS)**
- **Apex classes**

No need to switch between tools or consoles.

---

#### 🧱 Component File Creation  
Generate specific files within LWC components:
- `.html`, `.js`, `.css`, `.xml` (meta) 

Helps maintain a clean and modular project structure.

---

#### 🔍 Code Search  
Easily search through:
- LWC source files  
- Apex classes

Perfect for large codebases or fast navigation.

---

#### 🧾 Diff Checker  
Visually compare code versions side-by-side.  
Useful for:
- Code reviews and comparisons
- Refactoring   

---

#### 🧪 GraphQL Explorer  
Write, test, and run **GraphQL** queries directly in the browser. No external tools required.

---

#### 🔄 SOQL → GraphQL Converter  
Instantly convert your **SOQL queries** into **GraphQL** format. Great for transitioning to Salesforce's GraphQL APIs.

---

#### 💾 Backup & Download  
Download:
- Individual files  
- Full components  
- Folders or complete ZIP archives

Keep your projects portable and safe.

---

#### 🧹 Cleanup Tools  
Easily delete:
- Unused components  
- Individual files

Helps maintain a clean and optimized codebase.

---


# 📝 Editor Experience 
---

#### ⚡ Quick Deployment
Instantly save and deploy your code with a single shortcut:  
`CTRL + S` (Windows) or `⌘ + S` (Mac)  
No extra clicks—just save and go.

---

#### 🧩 LWC Snippets
Speed up development with a rich library of **[code snippets](/cheatsheet)** for Lightning Web Components. Insert common patterns and boilerplate with just a few keystrokes.

---

#### 🌗 Theme Modes
Toggle between:  
- 🌙 **Dark Mode** for low-light environments  
- ☀️ **Light Mode** for daytime clarity  

Switch anytime to match your workflow and mood.

---

#### 🎨 Customizable Themes
Choose from a range of color themes to personalize your coding space. Whether you prefer minimal or vibrant, there's a theme for every developer style.

---


_Enjoy faster, smarter Salesforce development with Lightning Studio!_
